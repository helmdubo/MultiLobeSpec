Новый уровень и правки Engine не создавались. Экспериментальный `Native Weather Preview` по-прежнему выключен по умолчанию. Полевые сценарии ниже ещё не приняты целиком; установка, последняя сборка и проверка поворотов — [`FogMS_CloudHost_EditorBinding_Verification.md`](FogMS_CloudHost_EditorBinding_Verification.md).

## Что изменилось

При включённом `Native Weather Preview` подсистема FogMS ставит **только компоненту своего Volumetric Cloud Host** `Shadow View Sample Count Scale = 1.6` вместо сохранённого масштаба (обычно 3.2). В UE 5.8.2 фактический верхний предел равен `min(10 × scale, r.VolumetricCloud.Shadow.ViewRaySampleMaxCount)`: при штатном глобальном cap80 это 16 вместо 32 шагов. Другие облачные компоненты и глобальный cvar не меняются. Выключение Preview, Clear или прекращение подачи погоды возвращает масштаб Host. `r.FogMS.Weather.ShadowViewSampleScale 0` оставляет авторское значение; его ручная правка в Details во время Preview получает приоритет до следующего включения Preview. Изменение не требует пересборки шейдера.

## Сборка и предел проверки W51c до установки (27.09)

Свежая staged-копия плагина собрана UE 5.8.2 `RunUAT BuildPlugin -TargetPlatforms=Win64 -StrictIncludes`: Editor, Game Development и Shipping **успешно**, без PCH и unity. `Build.log` и пакет: `E:/GITHUB/MultiLobeSpec/.codex-build/WeatherCoherence_20260927_W51c/`. Исходники `FogMS_CloudHost.cpp/.h` в staged-копии совпали по SHA-256 с рабочей веткой. Предупреждения C4701 для `Phase0/1/2` в неизменённом `FogMS_BoxVolume.cpp` остались; Shipping не запускался.

Отдельный временный проект с **копией того же FogMS_Box**, пакетом W51c и новой DLL подтвердил жизненный цикл свойства. Первые пробы без `-BindlessAll` имели PIE-время 0.0 с и не давали Weather выполнить тик; они не являются проверкой W51c. Финальный прогон с `-BindlessAll` и захватом кадра, который запустил обновление headless PIE, прошёл все проверки без ошибки (`RuntimeTest/Editor5.log`, `w51c_runtime_result4.json` в staged-каталоге). Состояние Broken + Preview переводит Host **3.2 → 1.6**; Preview off возвращает **3.2**; cvar **0 → 1.6** при активном Preview даёт **3.2 → 1.6**; ручная правка Host на **2.4** сохраняется до следующего переключения Preview; после него Preview снова ставит **1.6**, а выключение возвращает новый авторский базис **2.4**. Clear сохраняет **2.4**. Во всех точках глобальный cap UE оставался **80**. Это проверка поведения компонента, а не визуальная приёмка погоды. Установленную DLL и открытый редактор владельца я не заменял и не перезапускал.

## Оставшаяся полевая проверка после установки

Пакет уже установлен, та же карта открыта. Для сравнения использовать штатный глобальный лимит `r.VolumetricCloud.Shadow.ViewRaySampleMaxCount 80`, а не прежний временный console cap16. При Clear/Preview off Host должен иметь прежний авторский масштаб (обычно 3.2); Broken + `Native Weather Preview` — 1.6; `r.FogMS.Weather.ShadowViewSampleScale 0` при том же Broken должен сразу вернуть авторский масштаб, повторное `... 1.6` — снова 1.6, выключение Preview/Clear — авторский масштаб. Затем сравнить непрерывный W/S, Overcast и Broken при дневном/низком солнце, наземную тень и SkyLight capture. Если что-то ухудшится, `r.FogMS.Weather.ShadowViewSampleScale 0` возвращает старую цену/качество без пересборки.
