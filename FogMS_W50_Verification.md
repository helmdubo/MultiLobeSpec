# W50: проверка согласования погоды, 27.09.2026

Ветка `codex/weather-coherence`, база `main` `7c5316c`. Движок UE 5.8.2 не изменялся. Установлено в существующий MimirHead; использована только карта `/Game/FogMS_Test/FogMS_Box`.

## Проверено

- `BuildPlugin -StrictIncludes`: UnrealEditor, UnrealGame Development и Shipping — успешно. Shipping проверен сборкой, не запуском игры.
- Запуск редактора D3D12/SM6 с новыми global shaders — успешен. Первая попытка обнаружила неподдерживаемые парсером UE групповые объявления параметров; объявления разделены, повторный запуск успешен.
- Материалы `M_FogMS_Cloud` v5, `M_FogMS_WeatherSun`, `M_FogMS_WeatherSky` скомпилированы и сохранены. Обратное чтение графа Cloud: 18 Custom nodes, 148 pins. Повторный запуск обоих генераторов: `ALREADY_PATCHED`.
- В редакторе: Overcast → Clear → Overcast → Disabled → Enabled. Параметры `WeatherOn/WeatherLightingOn` переходят 1/1 → 0/0 → 1/1; существующий host локального Box сохраняет тот же объект. Отдельный путь восстановления заимствованного weather-only host проверен кодом и сборкой, не этим сценарием.
- Box использует общий ветер 2 м/с вдоль +Y; выключение Weather возвращает авторский локальный ветер `(171.43346,103.007615,0)` см/с. При переключении источника ветра в фиксированное время все три мировые фазы плотности сохраняются: максимальная разница `0.0`.
- Плавный трёхсекундный переход Overcast → Clear завершился; карта погоды обновлялась в процессе и освободила погодное влияние в конце.
- При Overcast решатель активен с `SH (Real Time Capture, weather clouds)`, при Clear возвращается к Sky View LUT. A/B `Light Local Clouds` изменяет солнечное освещение локального облака, сохраняя купол и тени погоды. Это функциональная проверка, не доказательство полной физической точности купола.
- SHA256 установленных 74 файлов Source/Shaders совпадает с текущим checkout, трёх DLL — с собранным пакетом. Обновлённые материалы добавлены и в локальный пакет после проверки в редакторе.

## Стоимость и визуальные ограничения

Контрольные одиночные GPU-кадры: 1104×813, замороженная плотность/ветер, Overcast, Sun Softness 5°, SolveInterval временно 1. Проход солнечного источника: **0.126 мс bypass / 0.330 мс W50**. Сумма событий транспорта: **1.89 / 2.08 мс**. Это не усреднённый benchmark.

Полный кадр 17.51 / 11.80 мс нельзя трактовать как общее ускорение: при закрытом погодой солнце нативный CloudView выполняет меньше работы (7.016 / 1.097 мс). Стоимость меняется с погодой, высотой Box и направлением света. В обычном режиме возвращён SolveInterval=2.

На сохранённом низком солнце видимое погодное небо остаётся неубедительным: плоские слои и сильный цветовой вклад купола. W50 связывает его с локальным светом, но не исправляет модель неба. Следующий приоритет — объёмный погодный слой; см. [направление](FogMS_Weather_Coherence.md). Закатная сферическая трассировка, два atmosphere lights и пространственное затенение неба пока не закрыты.

При переключении realtime viewport тестовым API UE выдал `Ensure ... bCheckMissingOverride || bRemoved`; редактор продолжил работу. После снятия фонового ограничения подтверждён Active B3. Первый прогон проверки ветра ошибся из-за позиционных аргументов Python Rotator (roll вместо yaw); исправленный прогон с именованными аргументами прошёл. Эти события не скрыты из журнала.
