# Проверка переносимых B2 harness

Проверено offline, без запуска/управления UE, сборки или установки. Реальные GPU результаты portable-копий этим документом не утверждаются.

- Все восемь Python-файлов проходят `compile()`; импорты entry не загружают `unreal` и не запускают работу.
- Для numeric и wall проверены три варианта baseline: поле отсутствует, `null`, отсутствующий файл. Все шесть вариантов проходят; 21 mock-сценарий восстановления завершился успешно.
- Обычный wall при отсутствии нового CVar сохраняет совместимость с Package5. При наличии CVar проверен цикл исходное `1` → временное `0` → восстановленное `1`.
- Reconstruction проверен на шести synthetic случаях/трёх парах. Невалидный alpha, NaN, утечка за стеной, тёмный контроль и старая flux-схема отклонены. Fake Unreal подтвердил принятие новой barrier/measurement metadata, восстановление `0 → 1 → 0`, stop/error/timeout и отказ до мутаций при отсутствии CVar. Это проверка harness/analyzer, не native GPU sampler.
- AST обычного numeric-анализатора совпадает с исходным, кроме пути `DEFAULT_ORACLE`; AST обычного wall-анализатора совпадает полностью. Копии reconstruction-анализатора одинаковы побайтово. SHA исходных файлов записаны в [PROVENANCE.json](PROVENANCE.json).

Изменения относительно исходного harness ограничены переносимыми путями, необязательным baseline/provenance, защитой entry от запуска при импорте, example ids, документацией и отдельно запрошенным reconstruction-режимом. Wall содержит исправление UE Python API через Actor setters. Уравнения стандартных анализаторов, интервалы capture и последовательность восстановления сохранены.

Исходные GPU receipts остались вне репозитория. Перед reconstruction-дополнением сохранена копия исходного wall harness в `FogMS_B2_20260921/gpu_wall_standard_v1`. Генерируемые дампы и локальные `_verification/`-материалы исключены через `.gitignore`. Изменений Engine, commit/build/install не выполнялось.
