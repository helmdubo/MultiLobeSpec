# FogMS B3: полевая проверка

Проверять в прежней карте `/Game/FogMS_Test/FogMS_Box`, актор `FogMS - Live Box`. Новый уровень не нужен. Параметры меняются вживую, без Apply.

## Перенос света

1. В Scattering Mode выбрать **Transport (B3 Angular)**, Angular Quality = **48 Directions**, Transport Iterations = **24**.
2. Для сравнения выбрать **Transport (B2)**. Это прежний алгоритм с шестью направлениями. Сохранить одинаковые плотность, положение камеры и источников. Если анимация включена, сначала нажать **Freeze Density Animation**.
3. **96 Directions** — дополнительная проверка угловой точности; её стоимость выше. Размер пространственной сетки остаётся 32³.
4. Выключение **Enabled** у Box возвращает штатное освещение его плотности. Вернуть Enabled для FogMS. Scattering Distribution у Height Fog пока должен быть **0**: анизотропное рассеяние ещё не реализовано.
5. При зуме и перемещении камеры свет внутри неподвижного объёма не должен накапливаться после остановки. Проверить границу тени колонны и затем солнечное/небесное освещение по отдельности.

## Движение плотности

1. **World Aligned Texture** включён. World Texture Size задаёт размер повторения в сантиметрах; растягивание Box изменяет только границы.
2. В Density Animation включить **Animate Density**. Например, Wind Velocity `(80,0,0)`, Detail Velocity `(0,12,0)`, Evolution Velocity `(0,0,5)` cm/s. Базовый рисунок движется по +X; детали постепенно меняют форму.
3. Проверить одновременно туман, его самозатенение и тень на земле. Они должны следовать одной плотности. Это движение текстуры, не симуляция жидкости.
4. **Freeze Density Animation** останавливает рисунок. **Resume Density Animation** продолжает с текущей фазы. Manual Animation Time воспроизводит конкретную фазу; ручной скачок времени намеренно отвергает старую историю один раз.
5. Animate Density = off возвращает исходное статическое отображение. Не менять плотность/альбедо для компенсации яркости при сравнении алгоритмов.

Провал проверки: устойчивый свет за сплошной стеной, рост яркости при неподвижной камере, отдельное движение тени от плотности, растягивание world-текстуры при resize, скачок фазы при Freeze/Resume, длинный шлейф или мерцание движущихся деталей. Полная пиксельная резкость ограничена сеткой native Volumetric Fog и её временной реконструкцией; B3 не является попиксельным рендерером облаков.
