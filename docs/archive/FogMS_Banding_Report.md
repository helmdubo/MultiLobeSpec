# FogMS — сглаживание солнечного самозатенения, 2026-09-21

Добавлен **Filter Sun Inside Volume** в Details → FogMS → Sun. Это отдельное live-сравнение мягкого и обычного солнечного самозатенения. По умолчанию нового класса выключен; в рабочей FogMS_Box включён при доставке. Использует существующий **Shadow Filter Sigma = 100 cm**; увеличение до 150–200 cm сильнее смягчает свет, но также смягчает тень на поверхностях.

## Что изменилось

- Самозатенение теперь считается в той же jittered позиции, что native lighting, для каждого supersample. Раньше оно считалось один раз в центре froxel. Tau/Transmittance сбрасываются перед каждой выборкой; native цикл сам усредняет результат. Overlay identity: `receiver=2`.
- Новый opt-in читает уже подготовленный filtered sun transmittance cache 128×128×65 внутри авторской среды. Фильтруется пропускание, а не плотность или готовое изображение. Нет нового animated dither и нового GPU-прохода.
- `row16.z` передаёт новый флаг; Box ABI остаётся 24 строки. Изменение флага входит в обычный history reset. Новых render ресурсов, async consumers и lifetime правил нет.
- Ветка работает только при Authored Sun Shadow, Cast Sun Shadow, Filtered Sun Shadow, готовом cache, совпадающем основном солнце и MaxDistance не меньше диагонали Box. Иначе остаётся прежний march. Аналитический height fog добавляется отдельно; VBuffer не учитывается повторно.
- Эффективный Tau равен `-log(max(Tfiltered, exp(-80)))`. Это художественная фильтрация видимости: она смягчает и настоящие узкие световые лучи. В Octaves используется этот эффективный Tau; это не точное усреднение каждого порядка рассеяния.

Основные файлы: `MultiLobeShaderPatcher.cpp`, `FogMS_BoxVolume.h`, `FogMS_BoxRuntime.cpp`, `FogMS_Indirect.ush`. Engine не редактировался. Compatibility guard против предыдущего D3D12 crash сохранён без изменений; ParallelTranslate остаётся 0, HWRT/RT-тени включены.

## Что удалось установить

Evidence: `E:/GITHUB/MultiLobeSpec/.codex-build/FogMS_Banding_20260921`.

В исходном открытом процессе выключение пространственного переноса не убрало полосы. Изменение TLV32→16, tracing N8→16 и fog Z208→384 также не дало заметного улучшения. Увеличение authored sun march 64→256 (включая внутренний clamp) почти не изменило рисунок. MaxDistance=.01 убрал выраженное самозатенение вместе с полосами. Это локализует вклад солнечной medium visibility, но не доказывает, что все полосы ошибочны: физические shafts при этом тоже исчезают.

Большой native jitter разбивал рисунок, но давал зерно; его не оставляли. Исходный multiplier 0 восстановлен. Прежний выбор TLV RC=0/Jitter=0/N8 сохранён.

Между перезапусками изменилось наблюдаемое освещение даже при сохранённых авторских параметрах. Поэтому исходный screenshot и новый процесс **не являются чистым before/after доказательством receiver-поправки**. В новом процессе временный fixed-center probe не воспроизвёл прежние сильные полосы. Исправлено подтверждённое рассогласование выборок, но первоначальный дефект во всех условиях не объявляется закрытым. Диагностические варианты шейдера полностью удалены из установленного пакета заменой на проверенный Package2.

## Проверка поставляемого варианта

- Свежий `BuildPlugin -StrictIncludes`, non-unity/no-PCH: Build2/Package2, успешен. 72 установленных файла совпали по SHA256; 48 source/shader файлов staging совпали с репозиторием, 6 исходных Engine anchors не изменились.
- Реальный D3D12/SM6: `final-filter-off` / `final-filter-on` в одном процессе, одна камера, одинаковые плотность/солнце/Sigma100. Включение смягчает затенение и слегка высветляет закрытые области; геометрия маски плотности не меняется.
- Серии по 8 кадров, 1479×954: temporal luminance STD в ROI полос 0.001137 Off / 0.001097 On; в широком cloud ROI 0.001239 / 0.001279 (нормализованный display RGB). Существенного роста статического шума в этих сериях нет; это не гарантия отсутствия мерцания во всех сценах. Координаты ROI и скрипт находятся в `analyze.py`, результат — `image-measurements.json`.
- По одному GPU profile на режим: LightScattering 3.326 ms Off / 1.888 ms On, grid311×201×208, SS4. Это иллюстрация замены марша cache lookup, **не устойчивый benchmark полной стоимости кадра**.
- Spatial HDR readback: все значения finite/nonnegative, alpha в [0,1]. Подтверждает корректный выход экспериментального переноса в этом кадре, не доказательство физической точности MS.
- 120 секунд / 2321 Slate callbacks с движением камеры/солнца и скрытием существующего occluder завершились без ошибок, restoration_ok=true. Результат и восстановление сцены: `final-camera-sun-soak.json`. Итоговая установка и сохранение параметров: `delivery-receipt.json`.

## Как сравнить

1. В существующей `FogMS_Box` выбрать **FogMS - Live Box**.
2. В **FogMS → Sun** переключать **Filter Sun Inside Volume**. Apply не нужен. Дать истории несколько секунд успокоиться после переключения.
3. **Shadow Filter Sigma**: 100 cm — текущий вариант; 150–200 cm — мягче. Он влияет также на тень FogMS на земле. Для отключения только сглаживания внутри объёма достаточно выключить Filter Sun Inside Volume; остальные галки оставить включёнными.
4. Ожидается более плавный рисунок солнечного света; небольшая прибавка света в ранее тёмных узких участках допустима. Плотность, Perlin, silhouette и физические широкие тени сохраняются.
5. Провал: появление нового мерцания, пропажа всей тени, смена формы плотности при одном переключении, NaN/чёрные вспышки, зависимость эффекта от случайного запуска. Зафиксировать ракурс и состояние солнца, сравнить Off/On без перезапуска.

В рабочем уровне сохранены Density=.8, SpatialStrength=.5, SpatialDistance=2000 cm, IndirectSteps=32, authored Sigma100 и последнее пользовательское положение камеры. Новых уровней нет. Визуальная приёмка владельцем остаётся отдельной.
