# FogMS: проверка подготовленных теней и Spatial

Протокол для **одного существующего FogMS_Box**, UE 5.8.2. Измеренные GPU-результаты и ограничения приведены в `FogMS_Fields_Report.md`; здесь — проверка владельцем в сцене. Всё работает через плагин MultiLobeSpec; изменения и fork Engine запрещены.

Использовать текущую сцену и исходный SkyLight: **Captured Scene, Intensity = 3, Real Time Capture = false**. Сохранить эти настройки во всех сравнениях; не делать recapture между A и B. Записать исходные параметры Box, Scattering Distribution тумана, экспозицию, положение камеры и солнца. Плотность и её материал уже должны работать. Не добавлять второй Box. Оставить `r.RDG.AsyncCompute=1`: принудительное значение 2 в стресс-тесте привело к RHI-сбою и не поддерживается.

| Параметр в Details | Значения для проверки |
| --- | --- |
| Cast Sun Shadow / Surface Shadow Strength | Включено / 1 для проверки облачной тени на поверхностях |
| Filtered Sun Shadow | Выкл. — исходный raymarch; вкл. — подготовленное поле для основного Atmosphere Sun, index 0 |
| Shadow Filter Sigma | 0 → 50 → 100 → 300 **cm**; допустимо 0–1000. Это стандартное отклонение фильтра, не Source Angle солнца |
| Scattering Mode | **Off (A1 Only)** → **Octaves** → **Spatial (Experimental)**; режимы взаимоисключающие |
| Spatial Strength / Spatial Distance | Strength: 0 → 0.15 → 0.35 → 0.5; Distance: 100 → 500 → 1000 **cm** (допустимо 10–2000) |

Для Spatial нужны один realtime perspective viewport, D3D12/SM6, hardware inline ray tracing, BindlessAll, `r.VolumetricFog.TemporalReprojection=1` и **Volumetric Fog → Scattering Distribution = 0**. Realtime viewport не означает Real Time Capture у SkyLight. Если Spatial Status просит **Enable Indirect Preview**, нажать кнопку один раз; она также включает Indirect Shadowing — вернуть этот флаг к исходному значению. Зафиксировать получившиеся настройки Lumen и Scattering Distribution для всех трёх режимов A/B. Не переключать preview-рецепт между снимками.

1. **База и готовность.** Выбрать Box в Outliner; при необходимости нажать **Enable Live Box** и дождаться компиляции. В одном кадре должны быть видны освещённая земля, столбы и облако. Начать с Scattering Mode = Off, Cast Sun Shadow = false. Сделать базовый снимок. После включения соответствующих полей проверять Surface Shadow Status: `Active filtered light-space transmittance`, Spatial Status: `Active experimental spatial transfer…`. Постоянный Waiting, ошибка или Reference march fallback означают, что соответствующий путь **не проверен**.

2. **Тень на земле и столбах.** Включить Cast Sun Shadow, Strength = 1, Filtered Sun Shadow = false; для эталона поставить Surface Shadow Steps = 64. Снять A. Включить фильтрацию с Sigma = 0 и снять B: расположение и общая форма тени должны совпадать; попиксельного равенства у разных дискретизаций не требуется. Затем пройти Sigma 50/100/300. Ожидание: облачная тень смягчается на земле и вертикальных поверхностях, обычные геометрические тени сохраняются. **Провал:** сдвиг тени, швы/клетки, чёрные полосы, тень перед облаком со стороны солнца или исчезновение тени целиком при небольшом Sigma.

3. **Движение.** При Sigma = 100 сначала двигать только камеру, затем отдельно сдвинуть/повернуть Box, затем немного повернуть солнце; каждый раз остановиться и вернуть исходное положение. Тень должна оставаться привязанной к миру и обновляться вслед за облаком/солнцем. При World Aligned Texture шум остаётся в мире, движутся границы Box. **Провал:** тень следует за камерой, остаётся старый отпечаток, появляется скачок на границе кадра или устойчивое мерцание после остановки.

4. **Три режима рассеяния.** С той же камерой, плотностью и настройками Lumen снять Off; затем Octaves при MS Contribution = 0 и 0.5; затем Spatial при Strength = 0/0.15/0.35/0.5, Distance = 500. После каждого изменения дать history прогреться 2–3 секунды. Нулевой вклад должен возвращать освещение к Off, сохраняя A1. Spatial заменяет Octaves; равной яркости этих приближений не требуется. В Spatial повторить Distance = 100/500/1000: меняется дальность соседнего вклада, не форма плотности. **Провал:** скачок плотности, двойное добавление режимов, изменение при нулевом вкладе, NaN/белые вспышки.

5. **Стабильность и стена.** Оставить Spatial Strength = 0.35, Distance = 500 и неподвижную камеру на 10 секунд; сравнить снимки на 3-й и 10-й секундах. Indirect не должен продолжать разгораться, пульсировать или превращаться в чёрные пятна. Для стены выбрать участок, где непрозрачная геометрия перекрывает путь между ярким туманом и затенённым участком; оба участка должны оставаться внутри кадра, стена — участвовать в ray tracing. Сравнить Off/Spatial. **Провал:** добавленная засветка проходит прямо сквозь сплошную стену или увеличение Distance позволяет её игнорировать. Обход света вокруг края стены не считать таким провалом. Если подходящего участка нет, отметить тест стены как Not Run.

6. **Выключатели.** По одному проверить: Filtered Sun Shadow = false возвращает исходный march; Cast Sun Shadow = false или Surface Shadow Strength = 0 возвращают обычное поверхностное солнце; Spatial Strength = 0 и Scattering Mode = Off убирают Spatial-вклад. Enabled = false убирает поля Box, но независимая Density Enabled сохраняет плотность. При Density Enabled = false не должно остаться отпечатка от уже отсутствующего облака. **Провал:** сохраняются старое затенение/рассеяние или выключатель затрагивает независимую плотность. Между пробами восстанавливать исходные значения, в конце вернуть всё записанное; Restore Standard Lumen использовать после A/B, если preview включали только для теста.

**Граница результата.** Spatial — экспериментальный A2: источники берутся из **frustum и fog history предыдущего кадра**, геометрия ограничивает перенос через HWRT. После camera cut/сброса history допустим короткий прогрев с возвратом к A1; источники вне прежнего frustum недоступны. Устойчивые следы после прогрева — провал. Зависимость от доступности источников за кадром остаётся ограничением этого среза. Завершение B и полноценное пространственное multiple scattering этим протоколом не заявляются.

Для отчёта: по каждому пункту **Pass / Fail / Not Run**, значения параметров, A/B с одинаковым кадром и короткое видео движения/мерцания. При ошибке приложить Surface Shadow Status или Spatial Status и фрагмент лога. Успешная сборка сама по себе не закрывает эти проверки.
